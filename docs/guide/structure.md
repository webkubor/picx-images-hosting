# 目录约定

- **`<项目名>/`**：该 GitHub 仓库的推广素材，命名建议 `logo.*`、`banner.*`、`og.*`、`demo.gif` + `demo.mp4`、`shot-*.png`
- **`temp/YYYY-MM/`**：临时图（`add.sh` / `imgbed push` 默认落点）
- **`free-imgbed/`**：本方案自己的 logo（吃自己的狗粮 🐶）
- **`blog/projects/…` 等历史路径**：只读保留，外链仍有效
- **`web/`**：配套 R2 相册应用快照；**`docs/`**：本文档站（VitePress）
