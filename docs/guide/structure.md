# 目录约定

- **`<项目名>/`**：该 GitHub 仓库的推广素材。现役标识用 `mark-v3.svg` + `mark-v3-dark.svg`（深浅成对）；其他素材用 `banner.*`、`og.*`、`demo.gif` + `demo.mp4`、`shot-*.png`。**每个项目只保留现役 logo，旧版不留在仓里**。
- **`temp/YYYY-MM/`**：临时图（`add.sh` / `imgbed push` 默认落点）
- **`free-imgbed/`**：本方案自己的 logo（吃自己的狗粮 🐶）
- **`blog/projects/…`**：历史文章配图路径，不新增 logo 版本
- **`web/`**：配套 R2 相册应用快照；**`docs/`**：本文档站（VitePress）

项目品牌的来源、共享关系与待设计项见 [品牌资产清单](https://github.com/webkubor/free-imgbed/blob/main/BRAND-ASSETS.md)。不要用 banner、截图或 favicon 自动冒充 logo；同一素材跨项目使用时共享一条链接。
