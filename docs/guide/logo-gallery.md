## 规范与来源

旧素材继续保留现有路径；新符号是版本化追加，尚未发布时 CDN 链接可能尚不可访问。选色依据和本次派生色的区别见评审页与 [交付说明](/design/logo-review.html#delivery)，历史路径和跨项目复用见 [品牌资产清单](https://github.com/webkubor/free-imgbed/blob/main/BRAND-ASSETS.md)。`ready` 表示本地 manifest 的设计资料状态，不表示远端发布成功。

新增资产先用 `tools/add.sh`，再更新 manifest。局部检查：

```bash
python3 tools/check-brand.py --render-dir /tmp/free-imgbed-brand
tools/gallery.sh
python3 tools/brand-ui.py --publish
tools/gallery.sh --check
python3 tools/brand-ui.py --check
```

像素校验需要 `rsvg-convert` 与 Pillow，缺依赖会非零退出。它检查透明角块、alpha 包围盒、留白与空图；32px 的辨识度仍需在深浅背景上观察。无铺底 `rect` 不能单独证明透明。全仓素材合规检查由 workflow 中的 `tools/check.sh` 运行。

## 页面真源

`brand/*.json`、项目目录 SVG 与 `design/briefs.json` 是输入；`tools/brand-ui.py` 生成仓内 `design/*.html`，其中嵌入从资产派生的预览，便于直接打开。`docs/package.json` 在开发和构建前执行同一生成器，再复制到被 Git 忽略的 `docs/public/design/`，不手工维护第二份 HTML 或图片。

品牌技能真源为 [本仓 SKILL.md](https://github.com/webkubor/free-imgbed/blob/main/.agents/skills/logo-brand-designer/SKILL.md)。
